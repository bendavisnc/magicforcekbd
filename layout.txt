Notes
  FN2_ Keycodes
    FN2A, F
    FN2B, D
    FN2C, S

  FN2_ behavior
    for example, 
      Hold FN2 and F -> Toggles FN2A layout
      Hold FN2 and F, release and press FN2 -> Locks FN2A layout (next FN2 press unlocks)


  `_` means the underscore key
  _ means not defined for layout
  FN is a physical key, so for example, FN + H -> [, so [ needs to be remapped to LEFT
