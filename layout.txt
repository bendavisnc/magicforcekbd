Notes

FN2 sublayer selectors

FN2A is selected with FN2 + F.
FN2B is selected with FN2 + D.
FN2C is selected with FN2 + S.

FN2 sublayer activation and locking behavior

Each FN2 sublayer has the same activation and locking behavior. The examples
below use FN2A (selected with F); apply the same behavior to FN2B/D and
FN2C/S.

Momentary activation:

1. Press and hold FN2.
2. While holding FN2, press and hold F.
3. FN2A is active only while F remains held.
4. Releasing F deactivates FN2A and returns to the base layout. This is true
even if FN2 is still held.

Locking the selected sublayer:

1. Press and hold FN2.
2. Press and hold F; FN2A becomes active.
3. While continuing to hold F, release FN2.
4. Still holding F, press FN2 again.
5. FN2A is now locked. Releasing F does not deactivate it.
6. Press FN2 again to unlock FN2A and return to the base layout.

The lock gesture is specifically a release-and-repress of FN2 while the
sublayer selector key (F, D, or S) remains held. Merely releasing FN2, or
releasing the selector before pressing FN2 again, must not lock the layer.

Only one FN2 sublayer should be active at a time. Locking a different FN2
sublayer should replace the previously locked FN2 sublayer.

Key notation

`_` (backtick, underscore, backtick) means the underscore key.

A bare `_` means that the position is not defined for that layout.

FN is a physical keyboard key. The keyboard firmware translates FN
combinations before they reach the host. For example, physical FN + H
produces `[`. Therefore, remap the resulting `[` keycode to LEFT in the
Base FN Layout rather than trying to remap the physical FN + H combination.
